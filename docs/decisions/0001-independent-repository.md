# 0001: 独立したリポジトリとして管理する

- 状態: 採用
- 日付: 2026-10-12

## 状況

本システムは、RootLens専用デバイスの録画を取り込むソフトウェアではありません。販売先ごとに異なるスマートフォンアプリを、現場のMacから複数台並列で操作・監視するためのものです。

RootLensの既存のデスクトップアプリとは、対象ユーザー、対応端末、実行環境、アップデートの契機、障害時の扱いが異なります。特に本システムは、iOS、Xcode、対象となるサードパーティアプリのUI変更に追従する必要があります。

## 決定

`field-app-orchestrator`という独立したリポジトリで実装を管理します。RootLensを含む個別のプロジェクトは、必要に応じてリリース版や外部インターフェースを利用し、制御の実装を各プロジェクトに複製しません。

## 結果

- リリースサイクルと障害対応を、対象アプリの変更に合わせられる
- RootLens固有のデータ取り込み・承認機能と依存関係を共有しない
- MinuteやClaruなどアプリ固有の画面・操作・遷移を、共通処理が読み込む操作定義として追加できる
- 独立性と引き換えに、配布、署名、運用ドキュメントを本リポジトリで管理する必要がある
