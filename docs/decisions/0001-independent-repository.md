# 0001: 独立したリポジトリとして管理する

- 状態: 採用
- 日付: 2026-10-12

## 背景

このシステムは、RootLens専用デバイスの録画を取り込むソフトではありません。販売先ごとに異なるスマートフォンアプリを、現場のMacから複数台並列で操作・監視するためのものです。

RootLensの既存デスクトップアプリとは、対象利用者、対応端末、実行環境、更新契機、失敗時の扱いが異なります。特に、このシステムはiOS、Xcode、対象となる第三者アプリのUI変更に追従する必要があります。

## 判断

実装は`field-app-orchestrator`という独立リポジトリで管理します。RootLensを含む個別プロジェクトは、必要に応じてリリース版や外部インターフェースを利用しますが、制御実装を各プロジェクトへ複製しません。

## 結果

- リリース周期と障害対応を対象アプリの変更に合わせられます。
- RootLens固有のデータ取込・承認機能と依存関係を共有しません。
- MinuteやClaruなどのアプリ固有操作を、共通実行器のコースとして追加できます。
- 独立性の代わりに、配布、署名、運用文書をこのリポジトリ自身で持つ必要があります。
