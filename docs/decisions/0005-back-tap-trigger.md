# 0005: 装着者は背面のトリプルタップで止める・再開する

## 状況

装着者は休憩やトイレのたびに撮影を止め、戻ったら再開します。帽子を外すだけでは録画が回り続けます。iPhoneは頭に付いていて画面は見えず、Macは離れた場所にあることがあります。

候補は、iPhoneの背面タップ、Macにつないだ Bluetooth のボタン、Macの画面のボタンでした。

## 決定

iPhoneの背面のトリプルタップに、Macへ切り替えを知らせるショートカットを割り当てます。`field-app`は`FAO_CONTROL_PORT`でHTTPの要求を受け、撮影を続けると止めるを切り替え、読み上げ用の短い文を返します。ショートカットはその文を読み上げます。

要求にはトークンを付けます。同じネットワークにいる別の端末からは切り替えられません。

## 結果

- 追加の機材が要らず、撮影アプリを前面にしたまま使える
- 受け付けたかどうかは読み上げでわかる。何も聞こえなければ届いていない
- MacとiPhoneの自動操作の接続が切れていても、ショートカットからの要求がMacに届けば、指示は記録され、つながった時点で反映される
- iPhoneからMacへのネットワークが届かないときは切り替えられない。そのときはMacのターミナルから指示する
