# 0005: 装着者は背面のトリプルタップで撮影を停止・再開する

開始と終了の操作は、[0008](0008-separate-start-and-pause-taps.md)で別の背面タップに分けました。

## 状況

装着者は、休憩やトイレのたびに撮影を停止し、戻ったら再開します。帽子を外しただけでは、録画が継続します。iPhoneは頭部に装着されているため画面は見えず、Macは離れた場所に設置されていることがあります。

候補は、iPhoneの背面タップ、Macに接続したBluetoothのボタン、Macの画面上のボタンでした。

## 決定

iPhoneの背面のトリプルタップに、Macへ切り替えを通知するショートカットを割り当てます。`field-app`は`FAO_CONTROL_PORT`でHTTPリクエストを受信し、撮影継続と停止を切り替え、読み上げ用の短い応答文を返します。ショートカットはその応答文を読み上げます。

リクエストにはトークンを付与します。同じネットワーク上の他の端末からは切り替えられません。

## 結果

- 追加の機材が不要で、撮影アプリを前面に表示したまま使用できる
- 指示が受け付けられたかどうかは、読み上げで確認できる。何も聞こえなければ、指示は届いていない
- MacとiPhoneの自動操作の接続が切れていても、ショートカットからのリクエストがMacに届けば、指示は記録され、再接続時に反映される
- iPhoneからMacへのネットワークが届かない場合は切り替えられない。その場合は、Macのターミナルから指示する
