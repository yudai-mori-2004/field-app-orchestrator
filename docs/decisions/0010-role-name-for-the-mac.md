# 0010: ショートカットの宛先は、Macの役割名にする

## 状況

背面タップのショートカットには、MacのURLを記述します（[0005](0005-back-tap-trigger.md)）。開発中は、開発用のMacのローカルホスト名をそのまま記述していました。

現場では、Macを現場ごとに設置し、iPhoneは複数台使用します。Macの個体名を記述すると、Macを交換する場合も、iPhoneを別の現場で使用する場合も、iPhoneのショートカットを修正する必要があります。

## 決定

- 現場に設置するMacのローカルホスト名を、役割名（`field-mac`など）にします。ショートカットのURLには、この名前を記述します。
- すべての現場のMacに、同じ名前を設定します。
- ポート番号とトークンは、従来どおりiPhoneごとに決め、そのiPhoneの設定ファイルに記述します。
- IPアドレスは固定しません。

## 結果

- Macを交換する場合は、新しいMacに同じ名前を設定し、iPhoneの設定ファイルを移します。iPhoneのショートカットは変更しません。
- iPhoneを別の現場で使用する場合は、その現場のMacに、そのiPhoneの設定ファイルを配置します。
- 名前はBonjourで解決します。端末間の通信やマルチキャストを遮断するネットワークでは解決できません。XcodeがWi-FiでiPhoneを検出するのも同じ仕組みのため、そのネットワークではもともと操作できません。
- 1つのネットワークに同じ名前のMacを2台設置すると、macOSが一方の名前を変更します。Macを2台設置する場合は、別の名前を設定します。
- すべてのiPhoneで同じショートカットを使用する方式（Macのエンドポイントを1つにし、iPhoneが自身の名前を送信する）は、Controllerの開発時に決定します。
