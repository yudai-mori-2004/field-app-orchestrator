# 0010: ショートカットの宛先は、Macの役割の名前にする

## 状況

背面タップのショートカットには、MacのURLを書きます（[0005](0005-back-tap-trigger.md)）。開発中は、開発に使っているMacのローカルホスト名をそのまま書いていました。

現場では、Macを現場ごとに置き、iPhoneは複数台あります。Macの個体の名前を書くと、Macを替えるときも、iPhoneを別の現場で使うときも、iPhoneのショートカットを直すことになります。

## 決定

- 現場に置くMacのローカルホスト名を、役割の名前（`field-mac`など）にします。ショートカットのURLには、この名前を書きます。
- どの現場のMacにも、同じ名前を付けます。
- ポートとトークンは、これまでどおりiPhoneごとに決め、そのiPhoneの設定ファイルに書きます。
- IPアドレスは固定しません。

## 結果

- Macを替えるときは、新しいMacに同じ名前を付け、iPhoneの設定ファイルを移します。iPhoneのショートカットは変えません。
- iPhoneを別の現場で使うときは、その現場のMacに、そのiPhoneの設定ファイルを置きます。
- 名前はBonjourで引きます。端末どうしの通信やマルチキャストを止めるネットワークでは届きません。XcodeがWi-FiでiPhoneを見つけるのも同じ仕組みなので、そのネットワークではもともと操作できません。
- 1つのネットワークに同じ名前のMacを2台置くと、macOSが片方の名前を変えます。Macを2台置くときは、名前を分けます。
- 全部のiPhoneで同じショートカットを使う形（Macの入口を1つにし、iPhoneが自分の名前を名乗る）は、Controllerを作るときに決めます。
