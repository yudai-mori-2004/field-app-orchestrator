# 0011: 背面タップでは、効果音を鳴らし、Macが指示を受け取った時点で返事をする

## 状況

[0008](0008-separate-start-and-pause-taps.md)では、背面タップの指示を受けたあと、画面で結果を確かめてから返事をしていました。録画が始まると「撮影を開始しました。」、止まると「撮影を終了しました。」と返し、30秒たっても結果が出なければ、時間がかかっていることを返していました。

- 背面タップで始めたり終えたりするのは、録画1本ではなく、録画を繰り返すループです。2本目からの録画はMacが自分で始めるので、返事を1本目の録画が始まるときに合わせる理由がありません。
- 「撮影を開始しました。」は録画が始まった後に読み上げられるので、声が録画に入ります。
- Macが動いていても、返事が返るのは約20秒後でした。Macに届いていないときも何も聞こえないので、装着者は20秒ほどのあいだ、届いたのかどうかを聞き分けられませんでした。現場を歩き回るとWi-Fiが切れることがあり、装着者がまず知りたいのは、Macに届いたかどうかです。
- 結果を待つために、返事を30秒で打ち切る仕組みと、時間がかかっていることを伝える文が要りました。
- ショートカットは、Macに指示を送る前に「撮影の準備をしています。お待ちください。」または「撮影を終了しています。お待ちください。」と読み上げていました。返事まで待たせることを前提にした文です。

## 決定

- ショートカットは、まず効果音を鳴らしてから、Macに指示を送ります。効果音は、背面タップが認識されたことを表します。
- `field-app`は、指示を受け取ったらすぐに返事をします。返す文は「撮影を開始します。」または「撮影を終了します。」です。Macが指示を受け取り、ここからループを始める、または終えることを表します。
- 返事のあと、`field-app`は画面を読んで、録画を始める、または止めるところまで進めます。iPhoneを操作できない間に受け取った指示は、操作できるようになってから進めます。
- 途中で進めなくなったことは、返事では伝えません。`field-app`の表示に出します。
- 終了の処理に入った`field-app`は、指示を受け取らず、文を返しません。

## 結果

- 効果音で背面タップが認識されたことが、続く声でMacに届いたことがわかります。効果音に続いて声が聞こえなければ、Macに届いていません。
- 開始の返事は、録画が始まる前に読み上げられます。Minuteの実機では、返事から録画が始まるまで約17秒でした。終了は録画中にたたくので、効果音と返事の読み上げは録画が止まる前に鳴ります。
- 返事を待つ時間の上限と、時間がかかっていることを伝える文はなくなりました。
- 録画が始まったこと、止まったことは、返事ではわかりません。
