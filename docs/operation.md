# 運用

[セットアップ](setup.md)を終えたあと、現場で動かすときのことをまとめています。

## 装着者に伝えること

- 背面を3回たたくと、撮影が始まります。30分ごとの録画の区切りはMacが処理するので、そのまま作業を続けて構いません。
- 背面を2回たたくと、撮影が止まります。休憩に入るときに使います。止めている間は、iPhoneを使って構いません。戻ったら3回たたきます。
- たたくと、まず効果音が鳴ります。たたいたことがiPhoneに伝わった合図です。続いて「撮影を開始します。」または「撮影を終了します。」と聞こえたら、Macに届いています。
- 効果音だけで声が続かないときは、Macに届いていません。Wi-Fiが戻ったときに、遅れて届くことがあります。
- 撮影中は、iPhoneの画面に触れないようにします。触ってもMacが録画に戻しますが、撮りかけの録画が失われることがあります。

背面タップの効果音と声は、iPhoneのスピーカーから出るので、録画に入ることがあります。開始のときは録画が始まる前に鳴り終わり、終了のときは止める直前の録画に入ります。

## 撮影を続けている間にMacがすること

録画が30分で区切られると、Macは上限のお知らせを閉じ、録画を保存または破棄して、次の録画を始めます。区切りから次の録画が始まるまでは、20〜25秒です。

次のことが起きても、Macが自分で録画に戻します。

| 起きたこと | Macがすること |
| --- | --- |
| iPhoneのWi-Fiが切れた | 10秒おきにつなぎ直す。撮影アプリは録画を続けていて、つながったら続きから進める |
| WebDriverAgentが止まった | 起動し直す |
| iPhoneが再起動した | WebDriverAgentを起動し直し、撮影アプリを開いてタスクを探し、録画を始める。撮りかけの録画は失われる。電源を切ってから約2分で録画に戻った |
| ホーム画面、ほかのアプリ、コントロールセンター、アプリの切り替え画面が開いた | 撮影アプリを前面に戻す |
| 画面がロックされた（通知センターが開いたときも同じ） | ロックを解除して、撮影アプリに戻る |
| 撮影アプリが終了した | 撮影アプリを起動し、タスクを探して録画を始める。撮りかけの録画は失われる。約80秒で録画に戻った |
| 撮影アプリに、操作定義にない画面が出た | 撮影アプリを起動し直し、知っている画面から進める。録画の画面のときは、起動し直さずに止まる |
| 電池残量の警告が出た | 「閉じる」で閉じて続ける |
| `field-app`が落ちた | launchdが起動し直し、起動し直した`field-app`が撮影を続ける |

撮影アプリが画面の操作でどう動くか（ホーム画面に出ると録画を止める、など）は、アプリごとのREADMEにあります。Minute Dataは[`apps/minute-app/README.md`](../apps/minute-app/README.md)です。

## 止まったとき

Macは、どう進めればよいか判断できない画面では、ボタンを押さずに止まります。たとえば、操作定義にないiOSの警告が出たとき、録画の画面に知らない表示が出たとき、撮影アプリがカメラの許可を求めたときです。止まっても、装着者には何も聞こえません。記録で見つけます。

1. 記録に`needs attention:`で始まる行が出ていないかを見ます。行の続きに、止まった理由が出ています。
2. iPhoneの画面を確かめ、出ている表示を閉じるか、必要な操作をします。
3. 背面を3回たたきます。止めたままにするなら2回です。Macは画面を読み直して、続きから進めます。

止まる場面の一覧は、[仕組み](architecture.md#止まるとき)にあります。

## 記録を読む

`field-app`の記録は、`~/Library/Logs/field-app/<FAO_DEVICE_LABEL>.log`に出ます。

```sh
tail -f ~/Library/Logs/field-app/minute-01.log
```

| 行の始まり | 意味 |
| --- | --- |
| `screen` | 読み取った画面。操作定義の状態の名前、`locked`（ロック画面）、`outside the app`（撮影アプリ以外が前面）、`system alert`（iOSの警告）、`unknown`（知らない画面）のどれか |
| `step` | 押したボタンや、した操作。かっこの中は、録画を始める、止める、保存する、破棄する、などの影響 |
| `phase stable` | 目標の画面に着いて、落ち着いている |
| `phase waiting for the app` | カウントダウンのように、撮影アプリが自分で進むのを待っている |
| `phase reconnecting:` | iPhoneとつながらず、つなぎ直している |
| `phase needs attention:` | 止まっている。続きに理由が出る |
| `requested` | 指示を受け取った。かっこの中は、どこからの指示か |
| `replied` | 背面タップに返した文 |
| `control port answered` | 背面タップの指示を受け付けなかった。理由が出る |
| `…の電池が残り…%になったので、撮影を止めました。` | 電池が減ったので撮影を止めた |

## 声が聞こえないとき

背面をたたいても効果音が鳴らないときは、iPhoneが背面タップを認識していません。「設定」の背面タップの割り当てを確かめます。

効果音のあとに声が続かないときは、記録を見ます。

| 記録 | 原因 |
| --- | --- |
| `control port answered 405 Method Not Allowed to GET /start` | ショートカットの「URLの内容を取得」の「方法」が`POST`になっていない |
| `control port answered 401 Unauthorized` | ショートカットのURLのトークンが、設定ファイルと違う |
| `control port answered 404 Not Found` | URLの`/start`や`/pause`が違う |
| 何も出ていない | 指示がMacに届いていない。URLのMacの名前とポート、iPhoneとMacが同じWi-Fiにいるかを確かめる |

## 電池

充電していない間に、電池が決めた残量（既定は10%、`FAO_BATTERY_STOP_PERCENT`で変えられる）まで減ると、Macは撮影を止め、Macの画面に通知を出します。撮りかけの録画は、止めて保存または破棄します。

止めたあと、充電せずに背面を3回たたくと、撮影を続けます。電池で止めるのは一度だけで、充電器につないだあとは、また止める対象になります。

充電しながらなら、録画を続けても電池は減りません。充電せずに撮影を続けたときの電池の減り方は、[確かめたこと](status.md#電池)にあります。

## 保存に切り替える

録画を提出するときは、操作定義の`afterRecording`を`save`に変え、サービスを入れ直します。

```sh
tools/service.sh install config/local/minute-01.env config/local/minute.json
```

入れ直すと撮影は止まるので、終わったら背面を3回たたいて再開します。

## iPhoneを足す

1. 動いているサービスを、すべて外します。WebDriverAgentを組み立て直すと、動いている`field-app`が使っている組み立て結果が消えるためです。

   ```sh
   tools/service.sh remove config/local/minute-01.env
   ```

2. 新しいiPhoneで、[セットアップ](setup.md)の2から5を行います。設定ファイルには、ほかのiPhoneと違うポートとトークンを書きます。
3. 外したサービスを入れ直し、新しいiPhoneのサービスを登録します（セットアップの6）。
4. 新しいiPhoneに、背面タップのショートカットを作ります（セットアップの7）。

## Macを替える

1. 新しいMacで、[セットアップ](setup.md)の1を行います。ローカルホスト名は、前のMacと同じ名前にします。
2. 前のMacの`config/local/`を、新しいMacのリポジトリに写します。
3. iPhoneを1台ずつUSBで新しいMacにつなぎ、「信頼」を選びます（セットアップの2「Macにつなぐ」の1と2）。iPhoneとの信頼は、Macごとに結びます。
4. WebDriverAgentを組み立て（セットアップの4）、サービスを登録します（セットアップの6）。

ポートとトークンが同じなので、iPhoneのショートカットはそのまま使えます。

## `field-app`を更新する

```sh
git pull
tools/service.sh install config/local/minute-01.env config/local/minute.json
```

iPhoneごとに`install`を実行します。`install`は、`field-app`を組み立て直し、動いているサービスを止めてから、新しいもので起動します。止めるときは、録画を止めて保存または破棄し、止めたときの画面まで進めてから終わります。終わったら、背面を3回たたいて再開します。

サービスを外すときは、`tools/service.sh remove config/local/minute-01.env`を実行します。

## ターミナルから動かす

試すときは、サービスの代わりにターミナルから`field-app`を起動できます。同じiPhoneのサービスを外してから使います。

```sh
set -a && . config/local/minute-01.env && set +a
swift run --package-path mac/controller-core field-app --definition config/local/minute.json
```

起動したあとは、次の言葉を入力して指示します。

| 入力 | 動作 |
| --- | --- |
| `start` | 撮影を続ける |
| `pause` | 止める |
| `status` | 今の指示と画面と、止まっているかを表示する |
| `retry` | 止まったあと、画面を確かめてから再開する |
| `quit` | 止めたときの画面まで進めてから終了する |

Ctrl-Cを押したときや、ターミナルを閉じたときも、`quit`と同じように終わります。

## 年に一度すること

WebDriverAgentの署名は1年で切れます。切れると、WebDriverAgentを起動できずに止まります。切れる前に、サービスを外してから[セットアップ](setup.md)の4をもう一度行い、サービスを入れ直します。
