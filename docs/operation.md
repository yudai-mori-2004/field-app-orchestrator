# 運用

[セットアップ](setup.md)完了後の、現場での運用についてまとめています。

## 装着者への説明

装着者には、次の内容を伝えてください。装着者への説明では、Macを「親機」と呼びます。

- 背面を3回タップ（トリプルタップ）すると、撮影が始まります。30分ごとの録画の区切りはMacが処理するため、そのまま作業を続けてください。
- 背面を2回タップ（ダブルタップ）すると、撮影が止まります。休憩に入るときに使います。停止中は、iPhoneを使用して構いません。休憩から戻ったら、トリプルタップしてください。
- タップすると、まず効果音が鳴ります。iPhoneがタップを認識した合図です。続いて「撮影を開始します。」または「撮影を終了します。」と聞こえれば、Macに指示が届いています。
- 「親機に接続できません。親機に近づいて、しばらく待ってからもう一度タップしてください。」と聞こえた場合は、その案内に従ってください。繰り返しても同じ場合は、担当者に連絡してください。
- 効果音だけで音声が続かない場合は、Macに指示が届いていません。Wi-Fiが復旧したときに、遅れて届くことがあります。
- 撮影中は、iPhoneの画面に触れないでください。触れた場合もMacが録画に戻しますが、録画途中のデータが失われることがあります。

背面タップの効果音と音声はiPhoneのスピーカーから出力されるため、録画に含まれる場合があります。開始時は録画開始前に再生が終わり、終了時は停止直前の録画に含まれます。

## 撮影中の自動処理

録画が30分で区切られると、`field-app`は上限到達のダイアログを閉じ、録画を保存または破棄して、次の録画を開始します。区切りから次の録画の開始までは20〜25秒です。

次の事象が発生した場合も、`field-app`が自動で録画を再開します。

| 事象 | `field-app`の処理 |
| --- | --- |
| iPhoneのWi-Fiが切断された | 10秒間隔で再接続を試みる。撮影アプリは録画を継続しており、再接続後に処理を再開する |
| WebDriverAgentが停止した | WebDriverAgentを再起動する |
| iPhoneが再起動した | WebDriverAgentを再起動し、撮影アプリを起動してタスクを検索し、録画を開始する。録画途中のデータは失われる。電源オフから約2分で録画を再開した |
| ホーム画面、他のアプリ、コントロールセンター、Appスイッチャーが表示された | 撮影アプリを前面に戻す |
| 画面がロックされた（通知センターの表示時も同様） | ロックを解除し、撮影アプリに戻る |
| 撮影アプリが終了した | 撮影アプリを起動してタスクを検索し、録画を開始する。録画途中のデータは失われる。約80秒で録画を再開した |
| 撮影アプリに未定義の画面が表示された | 撮影アプリを再起動し、定義済みの画面から処理を再開する。録画画面の場合は再起動せずに停止する |
| バッテリー残量のアラートが表示された | 「閉じる」で閉じて処理を継続する |
| `field-app`が異常終了した | launchdが`field-app`を再起動し、撮影を継続する |

撮影アプリ固有の挙動（ホーム画面に移ると録画が停止する、など）は、アプリごとのREADMEを参照してください。Minute Dataは[`apps/minute-app/README.md`](../apps/minute-app/README.md)です。

## 停止時の対応

`field-app`は、処理を判断できない画面ではタップを行わずに停止します（要対応状態）。たとえば、未定義のiOSアラートが表示された場合、録画画面に未定義の表示が重なった場合、撮影アプリがカメラへのアクセス許可を求めた場合です。停止しても装着者には通知されないため、ログで確認します。

1. ログに`needs attention:`で始まる行が出力されていないか確認します。行の後半に停止の理由が出力されます。
2. iPhoneの画面を確認し、表示を閉じるか、必要な操作を行います。
3. 背面をトリプルタップします（停止状態を維持する場合はダブルタップ）。`field-app`は画面を読み取り直し、処理を再開します。

停止条件の一覧は、[アーキテクチャ](architecture.md#停止条件)を参照してください。

## ログの見方

`field-app`のログは、`~/Library/Logs/field-app/<FAO_DEVICE_LABEL>.log`に出力されます。

```sh
tail -f ~/Library/Logs/field-app/minute-01.log
```

| 行頭 | 内容 |
| --- | --- |
| `screen` | 読み取った画面。操作定義の状態名、`locked`（ロック画面）、`outside the app`（撮影アプリ以外が前面）、`system alert`（iOSのアラート）、`unknown`（未定義の画面）のいずれか |
| `step` | 実行した操作。括弧内は操作の影響（録画開始、録画停止、保存、破棄など） |
| `phase stable` | 目標状態に到達し、安定している |
| `phase waiting for the app` | カウントダウンなど、撮影アプリの自動遷移を待機している |
| `phase reconnecting:` | iPhoneとの接続が切れ、再接続を試みている |
| `phase needs attention:` | 停止している（要対応状態）。後半に理由が出力される |
| `requested` | 指示を受信した。括弧内は指示の送信元 |
| `replied` | 背面タップへの応答文 |
| `control port answered` | 背面タップの指示を受け付けなかった。後半に理由が出力される |
| `…の電池が残り…%になったので、撮影を止めました。` | バッテリー残量の低下により撮影を停止した |

## 音声応答がないとき

背面をタップしても効果音が鳴らない場合は、iPhoneが背面タップを認識していません。「設定」の背面タップの割り当てを確認してください。

効果音の後に「親機に接続できません。」で始まる音声が流れた場合は、指示はMacに届いていますが、`field-app`が受け付けていません。ログで原因を確認します。

| ログ | 原因 |
| --- | --- |
| `control port answered 405 Method Not Allowed to GET /start` | ショートカットの「URLの内容を取得」の「方法」が`POST`になっていない |
| `control port answered 401 Unauthorized` | ショートカットのURLのトークンが、設定ファイルと一致しない |
| `control port answered 404 Not Found` | URLのパス（`/start`、`/pause`）が誤っている |
| `gave no reply to … (stopping)` | `field-app`が終了処理中 |

効果音の後に何も読み上げられない場合は、指示がMacに届いていません。iPhoneがWi-Fiの範囲外にある場合は、Wi-Fiが復旧したときに指示が届きます。Macの`field-app`が停止している場合や、URLのホスト名とポート番号が誤っている場合も、指示は届きません。iPhoneとMacが同じWi-Fiに接続されていること、サービスが稼働していること、URLが正しいことを確認してください。

## バッテリー

充電していない状態でバッテリー残量が設定値（既定は10%、`FAO_BATTERY_STOP_PERCENT`で変更可能）まで低下すると、`field-app`は撮影を停止し、Macに通知を表示します。録画途中のデータは、停止して保存または破棄します。

停止後、充電せずに背面をトリプルタップすると、撮影を継続します。バッテリー残量による停止は1回のみで、充電器に接続した後は、再び停止の対象になります。

充電しながら撮影する場合、バッテリー残量は減少しません。充電せずに撮影した場合のバッテリー消費は、[動作確認状況](status.md#バッテリー)を参照してください。

## 保存モードへの切り替え

録画を提出する場合は、操作定義の`afterRecording`を`save`に変更し、サービスを再登録します。

```sh
tools/service.sh install config/local/minute-01.env config/local/minute.json
```

再登録すると撮影が停止するため、完了後に背面をトリプルタップして撮影を再開してください。

## iPhoneの追加

1. 稼働中のサービスの登録をすべて解除します。WebDriverAgentを再ビルドすると、稼働中の`field-app`が使用しているビルド成果物が削除されるためです。

   ```sh
   tools/service.sh remove config/local/minute-01.env
   ```

2. 追加するiPhoneで、[セットアップ](setup.md)の手順2〜5を実施します。設定ファイルには、他のiPhoneと異なるポート番号とトークンを設定します。
3. 解除したサービスを再登録し、追加したiPhoneのサービスを登録します（セットアップの手順6）。
4. 追加したiPhoneの背面タップのショートカットを作成し、割り当てます（セットアップの手順7）。

## Macの交換

1. 新しいMacで、[セットアップ](setup.md)の手順1を実施します。ローカルホスト名は、交換前のMacと同じ名前にします。
2. 交換前のMacの`config/local/`を、新しいMacのリポジトリにコピーします。
3. iPhoneを1台ずつUSBケーブルで新しいMacに接続し、「信頼」を選択します（セットアップの手順2「Macとの接続」の1と2）。信頼の設定はMacごとに必要です。
4. WebDriverAgentをビルドし（セットアップの手順4）、サービスを登録します（セットアップの手順6）。

ポート番号とトークンは変わらないため、iPhoneのショートカットはそのまま使用できます。

## `field-app`の更新

```sh
git pull
tools/service.sh install config/local/minute-01.env config/local/minute.json
```

iPhoneごとに`install`を実行します。`install`は、`field-app`を再ビルドし、稼働中のサービスを停止してから、新しいバージョンで起動します。停止時は、録画を停止して保存または破棄し、停止状態まで遷移してから終了します。完了後、背面をトリプルタップして撮影を再開してください。

サービスの登録を解除する場合は、`tools/service.sh remove config/local/minute-01.env`を実行します。

## ターミナルからの実行

動作確認時は、サービスの代わりにターミナルから`field-app`を起動できます。同じiPhoneのサービスの登録を解除してから実行してください。

```sh
set -a && . config/local/minute-01.env && set +a
swift run --package-path mac/controller-core field-app --definition config/local/minute.json
```

起動後は、次のコマンドを入力して指示します。

| コマンド | 動作 |
| --- | --- |
| `start` | 撮影を継続する |
| `pause` | 撮影を停止する |
| `status` | 現在の指示、画面、停止しているかどうかを表示する |
| `retry` | 停止後、画面を確認してから処理を再開する |
| `quit` | 停止状態まで遷移してから終了する |

Ctrl-Cを押した場合やターミナルを閉じた場合も、`quit`と同様に終了します。

## 署名の更新（年1回）

WebDriverAgentの署名の有効期限は1年です。期限が切れるとWebDriverAgentを起動できず、`field-app`が停止します。期限が切れる前に、サービスの登録を解除してから[セットアップ](setup.md)の手順4を再度実施し、サービスを再登録してください。
