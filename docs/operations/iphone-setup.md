# iPhoneの初期設定

工場出荷状態のiPhoneを、`field-app`で操作できるようにするまでの手順です。1台ずつ、上から順に進めます。それぞれの設定が要る理由は、[iPhoneとMacの準備と運転](device-setup.md#初回セットアップ)にあります。

項目の名前は、iPhone 12 mini（iOS 26.4.1、日本語）のものです。iOS 17より前のiPhoneは操作できません。

## 1. 電源を入れてからホーム画面が出るまで

電源を入れると、初期設定の画面が順に出ます。次の画面では、書いてあるとおりに選びます。ほかの画面で選んだものは、あとから「設定」で変えられます。

1. 言語は「日本語」を、国または地域は「日本」を選びます。
2. Wi-Fiは、Macと同じネットワークを選びます。
3. Face IDの画面では、「あとで“設定”でセットアップ」を選びます。
4. パスコードを作る画面では、「パスコードオプション」を押し、「パスコードを使用しない」を選びます。
5. iOSのアップデートを勧める画面では、アップデートしない方（「あとでアップデート」）を選びます。
6. Apple Accountの画面では、撮影アプリを入れるのに使うApple Accountでサインインします。

## 2. 「設定」アプリで変えるもの

1. 「一般」→「情報」→「名前」を開き、ほかのiPhoneと重ならない名前（`minute-02`など）にします。
2. 「一般」→「ソフトウェアアップデート」→「自動アップデート」を開き、「iOSアップデート」の「自動インストール」をオフにします。
3. 「画面表示と明るさ」→「自動ロック」を開き、「なし」を選びます。
4. 「Face IDとパスコード」を開きます。「パスコードをオンにする」と出ていれば、パスコードはオフです。「パスコードをオフにする」と出ているときは、それを押します。

## 3. Macにつなぐ

1. iPhoneをUSBケーブルでMacにつなぎます。
2. iPhoneに「このコンピュータを信頼しますか?」と出たら、「信頼」を選びます。
3. iPhoneの「設定」→「プライバシーとセキュリティ」→「デベロッパモード」を開き、オンにします。再起動を求められます。
4. iPhoneを再起動します。再起動のあとに「デベロッパモードをオンにしますか?」と出るので、「オンにする」を選びます。
5. Macで次を実行します。iPhoneの名前の行の、最後のかっこの中がUDIDです。

   ```sh
   xcrun xctrace list devices
   ```

6. Macで次を実行します。iPhoneがTeamに登録され、WebDriverAgentが組み立て直されます。ほかのiPhoneを運転している間は実行しません。

   ```sh
   FAO_DEVELOPMENT_TEAM=<Team ID> tools/setup_wda.sh <iPhoneのUDID>
   ```

7. USBケーブルを抜きます。これからは、iPhoneがMacと同じWi-Fiにつながっていれば操作できます。

## 4. 撮影アプリを入れる

1. 撮影アプリを入れます。
2. 撮影アプリを開き、ログインします。
3. 撮るタスクを開き、録画を始めます。カメラなどの許可を求められたら、許可します。
4. 録画を止め、試しの録画を破棄します。
5. Minute Dataでは、表示が英語であることを確かめます。英語でないときは、Minute Dataの設定で言語を英語にします。

## 5. 背面タップを使えるようにする

この手順では、確かめるために録画を撮ります。撮った録画は、操作定義の`afterRecording`のとおりに保存または破棄されます。

1. Macで、このiPhoneの`field-app`を起動します。起動のしかたは[起動と指示](device-setup.md#起動と指示)にあります。
2. iPhoneで、[背面タップで止める・再開する](device-setup.md#背面タップで止める再開する)の手順のとおりに、「開始」と「終了」のショートカットを作り、背面タップに割り当てます。
3. iPhoneの背面を3回たたきます。「開始」と聞こえ、録画が始まると「録画を始めました。」と聞こえます。
4. iPhoneの背面を2回たたきます。「終了」と聞こえ、録画が止まると「録画を止めました。」と聞こえます。

## 確かめた範囲

- 「設定」アプリの項目の場所と名前は、運転しているiPhone 12 mini（iOS 26.4.1）の画面で確かめました。初期設定の画面とショートカットの項目の名前は、iOS 26.4の文言の一覧で確かめたもので、画面では確かめていません。
- 工場出荷状態のiPhoneで、この手順を最初から最後まで通したことはまだありません。1の画面は、iPhoneに入っているiOSのバージョンによって、順番や項目の名前が変わります。
- iOS 26.4.1のほかのバージョンでは確かめていません。
- 5の3と4は、Macから同じ要求を送って確かめた動きです。背面タップからはまだ確かめていません。
